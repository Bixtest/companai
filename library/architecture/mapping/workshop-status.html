CC-84 — tenancy, the defect that drove the whole study

Every worker MCP call authenticates as one superadmin service identity, so a Hermes turn can run platform tools outside the chat's tenant. There is one shared HERMES_HOME.

  • Per-run minted credential — recommended; it is SR-12, and it gates P2-9b.
  • Interim fail-closed guard — buys time, does not fix the boundary.
  • Doc-only — rejected: a documented defect is still a defect.
