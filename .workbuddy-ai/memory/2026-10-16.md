### ★★ THE BATCH'S RECOMMENDATION — the guard-as-document pattern (F5-3)
buzz encodes TWO frontend rules as **executable CI guards with shared cores**:
| guard | core | wrappers |
|---|---|---|
| `check-px-text` | `scripts/check-px-text-core.mjs` (129 L) | desktop only |
| `check-pubkey-truncation` | `scripts/check-pubkey-truncation-core.mjs` | desktop **+ web** |
| file-size ratchet | `scripts/check-file-sizes-core.mjs` | desktop / web / mobile |
Structure: shared core + thin per-app wrapper (`rules` + allowlist) → `package.json check`
→ `justfile check`. **A guard is applied where the rule is TRUE, not everywhere** (px-text
is desktop-only; pubkey is desktop+web).
- **`check-px-text`**: root cause = **PR #891** (message-timeline zoom regression). Rejects
  arbitrary `rem`/`em` TOO — *"arbitrary rem literals re-fragment the scale we just
  consolidated"* → **the rule is "one scale", not "no pixels"** (F5-5). `(?<!-)` lookbehind
  so `--font-size:` (3rd-party widget vars) is NOT matched. Windows path normalisation to
  posix *"or it silently matches nothing"*.
- **`check-pubkey-truncation`**: **a SECURITY invariant** — a truncated identifier a human
  trusts is **forgeable by vanity-grinding**; ad-hoc truncation had **fragmented into five
  formats**. Fix = centralise (`truncateNpub` / `truncatePubkey`) + fail the build (F5-4).
- **★ THREE allowlist mechanisms, each justified**: `allowedFiles` (the canonical module) ·
  `overrides` (**keyed by whatever is STABLE per-guard** — px-text pins the *literal*
  `…tsx:text-[6rem]` so line moves don't break it; pubkey pins the *line number* because a
  `slice()` call has no distinguishing literal) · wholesale `.test.` exclusion. **The choice
  of key shape is per-rule and is what a naive port gets wrong.**
- **Ratchet-not-freeze** (F5-7): `allowedLineCount()` = files already over the limit **may
  not grow**. Per-surface limits **desktop FE 1,200 / desktop Rust 1,500 / mobile 1,200 /
  web 1,000**. Deliberately **differential** (only files changed from merge base) → cheap
  enough for unconditional CI. Carries a comment naming its own past blind spot
  (`src-tauri/crates` was *silently* ungoverned; *"the check still exits 0"*).

### Design tokens = the strongest PX-W content (F5-6)
**TWO independent dials through ONE virtual rem**: (1) **Cmd +/- true zoom** over the real
root `<html>` rem (`useWebviewZoomShortcuts.ts`, clamped `[0.75, 1.5]` step `0.1`);
(2) a **text-only Font size preference** (`data-font-size`, ratio-valued
`calc(13/14)`/`calc(15/14)`). Both compose via `--buzz-type-rem: calc(1rem * var(--buzz-type-scale))`.
**★ The `lineHeight` scale is rem-relative TOO** — *"so Cmd +/- cannot enlarge glyphs inside
an unchanged line box"* (nobody thinks of this). Contract: conversation text = **13/14/15px**
before zoom. `2xs`/`3xs`/`badge` tokens replaced *"dozens of arbitrary text-[…rem] literals
that had drifted apart pixel-by-pixel."*

### Feature flags + internal/OSS split (§4)
- Manifest `preview-features.json` **zod-validated at startup**; invalid → **empty manifest** →
  *"nothing accidentally leaks."* **Fail-OPEN on unknown gates** (not in manifest = stable =
  renders; *"a stray `<FeatureGate feature="removed-id">` will never hide UI"*), **fail-CLOSED
  on the build split**. Two opposite answers to "what does *missing* mean?" (F5-12).
- `useFeatureEnabled` uses `useSyncExternalStore` with a **cached serialised snapshot** (the
  comment names the infinite-render hazard) + an explicit `getServerSnapshot` (F5-12).
- **`protectedFeatures/` = a verified build split (F5-13)**: `internal.ts`/`internalUi.ts` (real,
  15-file `bestie/`) vs `public.ts`/`publicUi.ts` (every export a documented no-op) behind the
  `@protected-features` alias. `build-protected-feature-artifacts.mjs` **builds BOTH variants and
  scans the EMITTED chunks** in both directions (no protected string in OSS; marker present in
  internal). `VITE_BUZZ_BESTIE` pinned explicitly so `.env.local` can't leak.
- **`tauri-command.mjs` closes a SILENT-SUCCESS failure mode (F5-14)**: Tauri's `frontendDist`
  untagged enum parses a **Windows absolute path as a URL (`C:` = scheme)** → embeds **zero
  assets, exits 0, boots to ERR_FILE_NOT_FOUND**. Fixed by always emitting a config-relative path,
  with a test that spawns the real wrapper + runs both variants concurrently. NOTE: the split is
  **commercial, NOT tenancy** — the tenant boundary is still the community (batch 03).
