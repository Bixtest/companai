### ★★ THE BATCH'S RECOMMENDATION — the guard-as-document pattern (F5-3)
buzz encodes TWO frontend rules as **executable CI guards with shared cores**:
| guard | core | wrappers |
|---|---|---|
| `check-px-text` | `scripts/check-px-text-core.mjs` (129 L) | desktop only |
| `check-pubkey-truncation` | `scripts/check-pubkey-truncation-core.mjs` | desktop **+ web** |
| file-size ratchet | `scripts/check-file-sizes-core.mjs` | desktop / web / mobile |
Structure: shared core + thin per-app wrapper (`rules` + allowlist) → `package.json check`
→ `justfile check`. **A guard is applied where the rule is TRUE, not everywhere** (px-text
is desktop-only; pubkey is desktop+web).
- **`check-px-text`**: root cause = **PR #891** (message-timeline zoom regression). Rejects
  arbitrary `rem`/`em` TOO — *"arbitrary rem literals re-fragment the scale we just
  consolidated"* → **the rule is "one scale", not "no pixels"** (F5-5). `(?<!-)` lookbehind
  so `--font-size:` (3rd-party widget vars) is NOT matched. Windows path normalisation to
  posix *"or it silently matches nothing"*.
- **`check-pubkey-truncation`**: **a SECURITY invariant** — a truncated identifier a human
  trusts is **forgeable by vanity-grinding**; ad-hoc truncation had **fragmented into five
  formats**. Fix = centralise (`truncateNpub` / `truncatePubkey`) + fail the build (F5-4).
- **★ THREE allowlist mechanisms, each justified**: `allowedFiles` (the canonical module) ·
  `overrides` (**keyed by whatever is STABLE per-guard** — px-text pins the *literal*
  `…tsx:text-[6rem]` so line moves don't break it; pubkey pins the *line number* because a
  `slice()` call has no distinguishing literal) · wholesale `.test.` exclusion. **The choice
  of key shape is per-rule and is what a naive port gets wrong.**
- **Ratchet-not-freeze** (F5-7): `allowedLineCount()` = files already over the limit **may
  not grow**. Per-surface limits **desktop FE 1,200 / desktop Rust 1,500 / mobile 1,200 /
  web 1,000**. Deliberately **differential** (only files changed from merge base) → cheap
  enough for unconditional CI. Carries a comment naming its own past blind spot
  (`src-tauri/crates` was *silently* ungoverned; *"the check still exits 0"*).
