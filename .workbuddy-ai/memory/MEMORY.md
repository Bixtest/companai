## Standing hazards
- **MASTER-CHECKLIST.html is DATA-DRIVEN** — content lives in the JS arrays (`PHASES`…`SRSREG`); edit an array entry, never the markup. The `.md` twin is hand-synced — the two DO drift.
- Pure LF, never CRLF; never a BOM.
- **A bare-word grep is NOT a declaration census** — use `^\s*capability\s*:`. Git-Bash `grep -c` on CR LIES; byte truth is `tr -cd '\r' < f | wc -c`. **Never `git add -A`** — explicit paths.
- **★ A CHECKER IS NOT A CONTROL UNTIL SOMETHING CALLS IT (found 2026-10-17, `CC-101`).** Four of seven drift checkers existed, passed their own tests and were mutation-proven — and were **called by nothing**. Before writing ✅ on any tooling item, name the caller: a CI step, a pre-commit hook, a gate. If the answer is "you can run it by hand", the honest state is **built but NOT ENFORCED**.
- **★ A ✅ IS A CLAIM ABOUT THE BUILD, so it is the most dangerous glyph in the register.** When re-verifying, re-read the *caller*, not the artefact. `ci.yml:499` and `:509` are the only two checker invocations of seven — measured by reading the workflow, not by listing `package.json` scripts.
- **★ HTML in the data arrays must escape `<` / `>`.** A raw `TS<digits>` or `Record<AutonomyGate, …>` inside a row is eaten by the browser, so the card renders less than the source says. Scan the extracted `<script>` for tag-like tokens that are not real tags.
