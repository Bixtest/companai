## CC-131 — found while proving the CC-124 commit was byte-clean (fixed, same day)

- **Found:** `git config core.autocrlf` = **`true`** and **no `.gitattributes`** in this repo. The *next*
  `git checkout` would have rewritten every text file to **CRLF** — including `MASTER-CHECKLIST.md`,
  whose entire discipline is byte truth (`tr -cd '\r' < f | wc -c`; *"a bare-word grep is NOT a
  declaration census"*). Silent corruption on an ordinary checkout, long after any commit.
- **Measured before fixing, so the fix is provably inert:** **zero** text files in HEAD contain a CR.
  The only five that do are binaries (`companai.ico`, `companai.png`, 2 PDFs, 1 `.docx`) — their CRs
  are data. So pinning changes no content.
- **Fix:** `.gitattributes`, `* text=auto eol=lf` **first**, binaries marked `binary` **after** — the
  last matching rule wins, so a wildcard placed last would erase the `-text` override.
- **Proof, not assertion:** `autocrlf` still `true`; forced `git checkout --` of the `.md` → **0 CR**,
  byte-identical; re-checkout of the `.png` → **sha256 unchanged**.
- Register **66 closed · 64 open · 130**. Checker PASS.
