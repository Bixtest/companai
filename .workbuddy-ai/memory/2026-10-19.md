### ★ The design insight that makes the build small
The invoker half splits in two: **holding** (`holdsCapability(person, feature)` — a feature-id
question, **no descriptor needed**) and **gating** (A0–A5 — needs one). `invokerCeilingFor` returns
early on `!capability` (`:495`), so holding is never asked for the 36. Asking it directly closes the
intersection rule for **all 157** without writing 36 descriptors.

### ★ A cycle that terminates only by coincidence
`di.ts:59` implements `holdsCapability` as `rbac.userHasAllFeatures(...)` — which calls
`refusedByAuthority` → `refusalFor` → `decideFor` → `invokerCeilingFor` → `holdsCapability`.
It stops only because `refusalFor` passes **no** options, so the inner call returns `null` at `:497`.
Any change that supplies an invoker unconditionally = infinite recursion. Requirement R4 is gated on
*an invoker being present* for exactly this reason.
